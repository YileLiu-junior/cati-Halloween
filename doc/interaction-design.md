2026-10-26。已确认：北京时间 2026-10-31 00:00 前 2 元，之后 5.9 元；取消装饰动画；用户评分、低分申请退款，不人工补生；两档同水印、无早鸟角标。后台、抠图选型和导出尺寸尚待确认。本文只维护方案，产品在另一个项目开发。

## 任务 1：快速审查

【原文证据】题目、角色、文案及 prompt 沿用 [quiz-design.md](quiz-design.md)；平局顺序以 [balance-check.py 第 95 行](balance-check.py#L95) 为准。

【跨源综合】只修影响落地的缺口：

1. 公开 ID 不能当领取凭证：另发私密找回口令。
2. 昵称、金额不能唯一认单：绑定支付标识，服务端核验平台订单。
3. KV 并发写会覆盖：订单幂等需原子凭证；本版取消数量库存。[KV 官方说明](https://developers.cloudflare.com/kv/api/write-key-value-pairs/)
4. 返回页面不代表付款成功：支付回流只触发查单。
5. 排队头不提供任务持久化或队位：补可靠后台，队位只算本站。
6. 浏览器关闭后长任务可能中断：不能用 waitUntil 保证完成。[执行期限](https://developers.cloudflare.com/workers/runtime-apis/context/#waituntil)
7. 倒计时不是价格裁判：后端按北京时间截止点校验，跨截止付款单独处理。
8. 照片七天删除会影响再次下载：上传前告知，成品显示到期日。

## 任务 2：开发规格

【模型补充】以下为开发约定。爱发电官方页面本次无法读取，支付参数须真单验通后启用收费。

### 1. 数据与完整旅程

L＝localStorage：匿名 ID、渠道、每猫 testId、题目版本、选项顺序、答案、名字、结果、口令、payId/jobId；不存照片。

K＝KV：验算结果、公开 ID、口令哈希、报价/订单/任务状态、次数、图键、到期日、评分、退款申请。R2 存私有图及原子凭证；订单认领与权益变更用条件写，鉴权/扣次读凭证，K 为镜像。[条件写依据](https://developers.cloudflare.com/r2/reference/consistency/#conditional-writes)

结果/订单/任务 API 校验口令；创建限流，密钥仅后端。服务端决定价格、角色、次数；订单/任务不缓存。主备域名共用 K/R2，换域须输口令。

### 2. 付费、绑定与找回（重点）

本模块估计 **0.75–1 天，待确认**。

1. **触发**：用户主动点“定制我家猫”才开付费墙。文案：“¥2 限时早鸟，距离恢复 ¥5.9 还有 HH:mm:ss。含 1 张猫咪黏土形象和完整角色卡。AI 会有差异；技术失败可免费重试 1 次，不像可评分并申请退款。”截止后改“早鸟已结束，¥5.9 定制”。两档权益相同。
2. **截止**：唯一截止点为 `2026-10-31T00:00:00+08:00`，即 10 月 30 日结束，不是 10 月 31 日结束。以前端获取的 serverNow 校准时钟，每秒显示剩余总小时/分钟/秒；小时可超过 99，不按天取模。回到前台及付款前重查报价。到 0 后隐藏倒计时、更新价格，不重置。后端才是价格裁判，取消 N、余量及超卖逻辑。
3. **跳出与跨期**：服务端生成 payId，固定 testId、角色、金额分值（200/590），早鸟报价到截止点失效。截止前支付成功的 2 元订单，即使之后才核验也可领取；未付跨期须明确确认新价，不静默改价。旧 2 元链接在截止后仍收款时，标异常、核实退款，不自动补扣差价。判断付款时间须验证平台真实字段；无法获得时转人工查订单详情，不能拿 API 查询时间替代。支付页优先携带 `custom_order_id=payId`，须真单验通；不可透传则复制 payId 填留言。不携带找回口令。
4. **回流**：跳出前显示“付款后，请返回本页点‘我已付款’。没有自动返回也没关系，请勿重复付款。”支持另开页则保留等待页，否则同页跳转。平台可配置的订单说明放“付款后返回测试页核对订单；找不到页面时，用已保存的找回凭证恢复。”本期不依赖自动跳回或回调。
5. **查单**：回页立即查，前台每 5 秒读本站状态，满 2 分钟改每 15 秒，满 10 分钟暂停；后台页停轮询。服务端全站最多每 15 秒拉一次平台订单，缓存合并请求并按页补齐；官方限制更严时从严。手动按钮冷却 15 秒，单 payId 每分钟最多 4 次，不能绕过全站频控。
6. **认单**：后端 API 核实交易成功、收款主体、商品/方案、实付金额与 payId；禁止仅凭截图、昵称或前端“已付款”解锁。用户可补填平台订单号定向核验；标识缺失时须在付款账号内联系作者人工核验。金额/商品不符显示“订单信息暂未匹配，请勿补付，联系作者核对”。

| 状态 | 进入条件／允许操作 |
|---|---|
| 未支付 | 已建 payId；可前往付款或返回免费结果 |
| 已支付待确认 | 用户自报已付，仅展示“正在核对付款”，不授予权益 |
| 已解锁 | API 核实且原子认领订单；允许上传 |
| 已使用 | 首次生成请求被接受；可查结果，仅技术失败允许第二轮 |
| 退款申请待核实 | 用户提交申请；暂停新生图，保留申请记录 |
| 退款中→已退款 | 人工核实后发起；冻结生成，保留免费结果 |

平台订单号全局只能认领一次；每个结果最多一个未完成 payId，只发一份权益。同 payId 多笔付款标记重复款，人工退多付部分。重复确认返回原 ID、原权益。调用前原子占用任务/次数；未终结任务返回原 jobId。技术失败重试沿用 jobId、新建 attemptId，原子扣第二轮额度。换背景、导出和评分均不调用生图。

找回凭证＝恢复链接＋128 位随机口令；链接用片段携带口令，不放公开卡片、支付链接、埋点或 Referer。首页可粘贴口令；刷新从 L 恢复，换浏览器/备用域名从 K/R2 恢复。提示“这是你的领取凭证，请私下保存。公开编号不能找回订单。”口令和链接都丢失时，走付款账号人工核验。结果元数据保留 30 天；未交付订单保留至交付或退款。

### 3. 上传与生成

使用系统照片选择器，允许相册选图，不强制相机；网页不能自行读取或排列整个相册。取消选择保留旧图；再次选择同一照片也响应；先确认预览完整，再开始上传。iCloud/其他云端照片可能需系统先下载，权限不足、格式解码失败、上传失败分别提示，不能都归成上传失败。详见技术补充的真机矩阵。

JPEG/PNG/WebP ≤10MB；压至长边≤1600px、JPEG ≤2MB，按 EXIF 校正方向后去除元信息；短边不足 512px 提示换图。HEIC 能解码则转 JPEG，否则提示“请转成 JPG，或上传截图”。不承诺全机型 HEIC 转码；若要求完整覆盖，需另加 **0.5–1 天，待确认**。后端复验格式/尺寸/大小；每口令/IP 每分钟审核≤3张，换图重审，通过前禁止生图。

隐私勾选默认关闭：“照片仅用于本次审核与生成，将发送给阿里云内容安全和火山方舟。我们不将照片用于训练。原照及生成图将在各自上传或生成后 7 天删除，请及时保存。请勿上传人脸、证件等隐私。我已阅读并同意上述处理。”上线前核实第三方条款。若抠图另用外部 API，须补充该供应商。R2 保持私有，到期接口拒绝读取；所有派生图继承原生成图的到期日，不因换底续期。主动清理并核验删除，生命周期只作兜底，不承诺仅靠该规则在第 7 天精确删除。[清理延迟依据](https://developers.cloudflare.com/r2/buckets/object-lifecycles/)

| 任务状态 | 展示／系统动作 |
|---|---|
| 审核中 | “正在检查照片…”；超时可重查，不扣生成次数 |
| 排队 | “本站预计第 N 位”；按本站待提交任务估算，不含平台队列；取不到数显示“正在排队” |
| 已提交 | “正在为它穿上万圣节装扮…”；平台不返回进度时不伪造百分比 |
| 形象处理 | 原图生图成功后只抠图一次，产出透明角色主图；五色背景由前端合成 |
| 完成 | 图片存入私有 R2 后标成功；前端绘制卡面文字，原始猫照片不进卡面 |
| 不确定/失败 | “还没拿到结果，请勿重复提交”；先核查原任务，再开放重试 |

### 4. 异常兜底矩阵（重点）

可靠后台估计 **0.5–1 天，待确认**：推荐加 Cloudflare Queue＋消费 Worker，保留 Pages/KV/R2；关页后继续。调用前持久化 attemptId，重复消息不重复调用；投递失败可重投同一 jobId。消费者单并发起步，按账号 IPM/RPM/并发节流；排队头须 Seedream 实测支持。[后台执行建议](https://developers.cloudflare.com/workers/runtime-apis/context/#waituntil)

每 5 秒查任务；2 分钟提示“比平时久一点，可稍后回来”；10 分钟停自动查询，保留“查询进度”。明确未受理的 429 按 Retry-After，缺失时 10/30/60 秒退避，三次仍失败转人工。5xx 明确失败最多补发一次。网络超时且受理未知不自动补发；请求总超时初设 180 秒，启用排队头后须覆盖排队＋生成预算。

每单最多两轮生图：首次＋技术失败自动重试一次，不含明确未受理的 429；不提供人工补生。按 0.2 元/张估计，两轮模型成本约 0.4 元，不含审核、抠图及云资源。成功但不像时走评分和退款申请，不再生图；两轮技术失败或受理不明无法交付也可申请退款。抠图、卡片重绘失败只重做对应步骤，不占第二轮生图。

用户评分已确认：成品页显示“像你家猫吗？请打 1–5 分”，可跳过，不拦下载。1–2 分显示“觉得不像？申请退款”；3–5 分保留问题反馈入口。申请理由必填：毛色/花纹不符、脸部差异、主体遮挡、背景处理异常、其他。提交后显示“申请已收到，我们将在 24 小时内核实。低分不会自动退款，请勿重复付款。”同订单只保留一条待处理申请，状态为待核实/退款中/已退款/不通过，说明处理结果。不自动用评分判定退款，也不做 AI 相似度评分。

| 场景 | 用户看到什么 | 系统做什么 | 可用文案 |
|---|---|---|---|
| 支付失败/中断/放弃 | 原结果、继续支付 | 保留 payId；不占生成次数 | “免费卡仍可保存；付款状态可稍后核对。” |
| 已付未确认 | 核对中、填平台订单号 | API 补查；10 分钟后给人工入口 | “请勿重复付款，可提供订单号核对。” |
| 重复付款 | 重复款提示 | 一份权益；人工退多付款 | “检测到多付，联系爱发电订单内作者处理。” |
| 照片审核拒绝 | 换图 | 阻断生图；不扣次 | “这张照片未通过检查，请换一张单猫清晰照。” |
| 审核服务故障 | 原预览、重试 | 阻断生图；保留权益 | “暂时无法检查照片，请稍后重试。” |
| 上传失败 | 原预览、重新上传 | 相同照片请求去重 | “上传中断，点击重试，不会重复扣次。” |
| 生图超时 | 查询/人工处理 | 标记不确定；禁止并发补发 | “结果还在核实中，暂时不用重新生成。” |
| API 配额/余额耗尽 | 已付保留权益 | 暂停新收费；恢复后继续或退款 | “生成暂时繁忙，订单已保留，可申请退款。” |
| 不像原猫 | 评分、低分退款申请 | 存评分/理由，24 小时内核实；不补生 | “觉得不像？请评分并提交退款申请。” |
| 透明形象处理失败 | 卡片可保存、头像可重试 | 重做抠图，不重新生图；持续失败可反馈 | “头像背景暂未处理好，完整卡仍可保存。” |
| 退出后隔天回来 | 继续任务/成品 | 先读服务端，再决定页面 | “欢迎回来，继续领取你的猫咪角色卡。” |
| 免费测第二只 | 新测试入口 | 新建 testId；保留旧结果 | “再测一只，免费。每张照片定制单独付费。” |
| 微信内无法支付/保存 | 浏览器引导/图片预览 | 展示长按图与可复制地址 | “点右上角，在浏览器打开；保存图片可长按。” |
| 早鸟到时 | 倒计时结束、¥5.9 | 新单用新价；未付旧报价须重新确认 | “早鸟已结束，继续定制为 ¥5.9；免费卡仍可保存。” |
| 截止后旧链接付 2 元 | 订单核对入口 | 不补扣、不假解锁；核实付款时间后处理退款 | “这笔付款需要核实，请勿再次付款。” |
| 图片已过七天 | 过期提示 | 删除 R2 图、撤销访问；不自动重扣 | “云端图片已删除，请查看此前保存的相册。” |

售后优先站内提交评分/理由，爱发电原订单联系作者兜底。承诺 24 小时内核实，不承诺 24 小时到账。实际退款操作与手续费退回规则须在爱发电账户中验证，本版不假设有退款 API；确认退款后冻结新的云端领取。图片已过保留期则不延长留存，必要时请用户经原订单补充凭据。

### 5. 导出与分享

“双导出”指完整角色卡与独立头像，不是生成两次。前端合成/保存估计 **0.5–1 天**；新增透明抠图选型与移动端验证估计 **0.5–1.5 天，待确认**，不含自建完整推理服务。

| 导出物 | 尺寸、内容、水印 |
|---|---|
