# 猫咪分角色 Prompt 集

> 本文件由旧版 `build.mjs` 生成，内容已过期。当前生效的 Prompt 与维护方式见 `README.md`。

最终发给模型的 prompt = `shared.md` + `【角色专属要求】` + `NN-role.md`。
每次只替换角色专属段，共享身份规则保持一致。合成后的完整 prompt 在 `combined/NN-role.txt`。

```text
请参考两张图片，生成一张 1:1 方形、纯白背景的 3D 宠物万圣节潮玩角色展示图。

【图片分工与身份优先级】
图一是唯一的宠物身份参考。角色必须让人认出是图一中的猫。毛色、色块分布、虹膜颜色、鼻子颜色、脸型、口鼻结构和耳朵形状，均以图一为准。

【图一猫咪的固定身份特征】

采用图二的圆润大头短身潮玩比例：头部约占角色高度三分之二，身体短小饱满，四肢短粗，爪子圆润。宠物裸露部位使用细腻、平滑的哑光软胶材质，用边界清晰的黑白色块表现毛色，不绘制毛发、绒毛、毛束或雕刻状毛纹。眼睛可使用光滑材质，与哑光脸部形成有限对比；不要把整个角色做成强反光的亮面塑料。
```

## 15 · 贪睡财神咪（gargoyle）

> 本轮修正：重点：只露一只前爪+一条后腿、闭眼睡觉、素红棉布垫。

```text
【角色：贪睡财神咪】
- 服装：红色财神帽，金色云纹滚边和金色帽正，帽翅向两侧伸出。
- 道具：一只前爪抱着一只大金元宝，旁边散落几枚金币。
- 姿势与场景：猫咪侧躺在垫子上，垫子必须是素色纯红棉布——没有绒面、没有绗缝、没有花纹、没有流苏、没有滚边、没有刺绣；垫子是唯一的地面道具，周围仍是纯白背景。头侧靠在金元宝旁，前胸贴住垫子，后腿蜷起。
- 睡眠表情：双眼必须完全闭合，左右两只眼睛都闭成向下的黑色弯线；不要睁开任何一只眼，不要眨眼，不要半睁，不要画瞳孔。
- 肢体数量（最高优先级）：画面中只能出现两只爪子——一只前爪搭在金元宝上，一条后腿在身体右后方露出。另一只前爪必须完全藏在胸口下方，另一条后腿必须完全藏在身体下方。禁止在元宝前方或垫子上再画一只前爪，禁止两只前爪抱元宝，禁止第三只、第四只脚。全图脚的总数只能是两只。
- 尾巴：纯黑为主，可白色尾尖；禁止环纹和灰色虎斑条纹。
- 如果构图无法同时放下元宝和两只爪子，优先减少爪子，不要增加爪子。
```
